# 车机一级与二级界面参考

核对日期：2026-10-02。本文为界面复建的研究依据与实现约定，不是功能完成或验收报告。车型继续采用享界 G9 纯电六座研究基线；手册同时包含五座、六座和选装说明，不能把所有功能无条件套用到六座车型。

## 来源与证据等级

主要来源为[鸿蒙智行官方使用说明书入口](https://hima.auto/xiangjie/service/)中的[《享界 G9 纯电版使用说明书》](https://hima.auto/dam/hima-site/cn/xiangjie/service/pdf/260911/%E4%BA%AB%E7%95%8CG9%E7%BA%AF%E7%94%B5%E7%89%88%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E%E4%B9%A6.pdf)，版本 G9OM26C1，2026 年 8 月。核对了本地 PDF（便携式文档）和对应逐页文本 `G9-pages.json`。下文均使用原 PDF 页码，本次核对页的页脚数字与文件页序一致。

- **图像依据**：实际查看了对应整页渲染，可以据可见的分区、相邻关系与控件形态原创重绘；仍不代表像素、字体、尺寸及所有状态完全一致。
- **文字依据**：手册明确记载入口、名称或操作流程，但本次没有对应完整界面图。功能路径可按资料组织，具体排版须标为改编。
- **设计补充**：原型为了可体验而增加的导航、模拟数据、确认、数值范围和本地设置。不得描述为原车完整行为。

本次实际查看的整页图为第 34、38、41、101、108、111、122、289、290、302、307、315 页。第 122 页包含多张灯光界面；第 302 页仅包含桌面媒体小卡，没有完整媒体应用页面。第 38、41、101、307、315 页主要是文字、表格或符号，不能据此宣称已得到应用中心、控制中心、座椅、声音、显示页的完整截图。手册图片仅在项目外临时渲染，不进入本仓库或发布资产。

## 已看图的布局重点

**桌面，第 34 页。** 状态栏和底部工具栏横贯屏幕。时钟位于大幅背景中上方，下部可见横向车灯卡、主驾坐姿卡、俯视车门卡、文件夹和独立应用图标。图中桌面属于可自定义的示例；不能据此把项目页签直接排成原车固定顶栏。

**灯光，第 122 页。** 设置侧栏位于左侧；可见车辆控制、灯光、能量、驾驶、辅助驾驶、车辆状况、智慧语音等条目，但截图没有证明完整列表。顶部有车内/车外灯光页签。主题页上半为座舱示意，下半为主题/自定义切换、灯光开关、亮度和横向主题卡。自定义页有位置选择、颜色面板及保存槽；灯光设置采用两列卡片。场景灯效以居中弹层覆盖原页面，具有总开关及智慧语音、上车迎宾、开门预警等分项。

**前排空调，第 108 页。** 前/后排页签在上部中央；空气质量位于左上，香氛位于右上；座舱背景两侧为温度，下部左右为风量、自动和风向，中部为同步、电源和制冷制热等操作，底部工具栏仍可见。第 109—110 页补充按钮含义、同步条件和“更多”内容。

**后排空调，第 111 页。** 画面为从后排看向前方的座舱背景，左右侧温度与上方前/后排页签保持关系；中下部是一条横向风量条，下方为自动及电源，左下有风向。该图不证明六个座位分别拥有独立空调系统。

**地图与导航，第 289—290 页。** 非导航态左上有搜索、收藏、家/公司卡；左下有设置、路况、充电站、更多、回自车及反馈；右上方向按钮、右下视图卡。导航态左上变为转向与距离面板，沿途路况条、绿波建议及路口倒计时按示例出现。道路名称、剩余时间和路线坐标在本项目中只能是模拟数据。

**媒体卡，第 302 页。** 图中是桌面背景上的一张小播控卡，包含封面/曲目信息及播放切换按钮，右上切换音源。只有这一卡片的可见结构有图像依据；把它扩展成完整音乐应用、专辑库或歌单页是设计补充。

## 复建与执行的共同约定

1. 页面切换、二级返回与弹层关闭须保持清楚：返回回到上一级，主屏幕键回到桌面；二者不应混用。浏览器为了操作方便新增的返回按钮要按设计处理。
2. 页面显示成功必须来自同一份车态或明确的本地界面状态。门窗、座椅、空调、灯光等已支持动作交给统一执行器，不能直接改画布文字而不更新三维实体与控制面板。
3. 声音、显示和连接的示例设置若仅在页面内生效，应标“本地模拟”；未接入的功能有解释或禁用状态，不用虚假的成功回执代替。
4. 地图搜索、路线、媒体、天气、空气质量和设备列表采用明确的模拟数据。不接入真实地图、账户、电话、网络或车辆，也不复刻厂商商标资源和软件包。
5. 页面树是证据支持的功能子集。完整原厂菜单、各软件版本差异、全部弹窗和异常态尚未查全；有页面图不等于所有配置或交互状态均已得到证明。

本轮文字核对中，第 109 页的极速制热说明出现增程器相关表述，与本项目纯电基线不一致；不把该表述用于纯电动力逻辑。任何涉及动力版本的条件需另按对应配置核实。
