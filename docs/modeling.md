# 座舱建模说明

本项目用原创参数化几何呈现享界 G9 六座座舱的可辨识结构，方便查看部件、理解语音控制对象和观察模拟动作。模型未经实车测量，不是原厂 CAD（计算机辅助设计）或汽车之家模型；部件尺寸、视角和动作比例属于教学近似。

## 当前实现

| 部分 | 表现方式 |
| --- | --- |
| 仪表台与中岛 | 依据实际查看的官方手册图重建贯通屏台、圆形三辐盘、竖向端风口和中岛；对照项及验收范围见下文。 |
| 座椅 | 连续曲面坐垫与靠背、侧翼、包边和缝线；前排按全景可见部分调整为单体圆角头枕、中央竖条和两侧穿孔、连续肩部软包与薄型电动拨键。 |
| 外观 | 与详细内饰统一装配：曲面分片、真实轮拱缺口、轮胎/轮毂、双圆灯组、窗框、车门、行李轨、侧裙与尾门小书包。支持车头、侧面、车尾观察，门窗与充电口共用一套实体和状态。 |
| 车体围合 | 门内饰、门框、玻璃、立柱、顶棚与地板构成车内空间；剖视用于观察遮挡后的部件。 |
| 材质与灯光 | 程序生成皮革颗粒、粗糙度、木纹及地毯纹理；中性摄影棚灯光、环境反射和 SSAO（屏幕空间环境光遮蔽）补充接缝与接触阴影。 |
| 观看方式 | 前舱、主驾、副驾和二排使用车内环视；拖动改变朝向，滚轮改变视野。座椅及全景视角支持绕模型旋转和缩放；座椅特写开启剖视时移除左侧围，关闭剖视可恢复。 |
| 内饰配色 | 橄榄灰、雅丹棕、云沙蓝三种近似配色，以及日间、夜间展示氛围；不代表经校准的原厂颜色或实车照度。 |

屏幕、门窗、座椅与气流仍读取同一份模拟状态；香氛和制氧保留状态及执行记录，缺少视觉依据的自创设备外壳已隐藏。新增外观细节不等于新增控制能力：怀挡、实体按钮、充电板及储物盖板等造型，不代表已实现对应的车辆服务或机械结构。

## 第四版：内外统一与公开车机界面复建

2026 年 10 月 2 日，第四版将第三版的内外独立展示改为同一车辆装配，并依据官方手册可见界面重绘大屏。第三版的分离方式仅保留在[历史验证记录](validation.md)和带 `v3` 的截图中，不代表当前实现。

`vehicle-assembly.js` 将车身与详细座舱装配到同一空间。四个内门板分别装在外门铰链下，升降玻璃只有一套；关闭剖视后，车内外视角看到的是同一组实体。剖视明确移除近侧壳体及顶棚遮挡，不是替换模型。原内饰几何使用比例 `[0.76, 0.70, 0.68]` 和位置 `[0, 0.09, 0.30]` 适配外壳，这是设计参数，未经实车测量标定。

车顶由周边边梁、前后蒙皮和中央透明天幕组成；中央有真实几何开孔，原座舱重复玻璃已清除，遮阳帘仍是独立可动作部件。四门玻璃、固定侧窗及前后风挡透明显示详细内饰，不以不透明玻璃遮盖占位模型。透明效果是展示近似，不能推定实车透光率。

第四版的 `screen-ui.js` 依据手册可见界面重绘图标、卡片、状态栏和底部工具栏，当时包含桌面、导航、车辆和空调四页；第五版已扩展为 20 页，完整路径及证据见[车机参考](infotainment-reference.md)。温度、车门、座椅与媒体读取模拟状态，屏幕点击交给现有执行器检查条件。

## 实际局限

外观与详细内饰现在共用一个车辆装配，切换内外视角只移动相机。外观中的占位座椅、仪表台与中岛已删除；详细内门板迁至外门的同一铰链，车窗及充电口也只保留一套动画引用。内饰通过程序比例适配外壳，并非原厂尺寸装配，局部接缝仍为近似。

没有原厂工程数据、实车测量、扫描数据或统一视角标定，因此不保证真实尺寸，无法给出尺寸误差和外观还原百分比。手册第 17—18 页不能完整证明座椅曲面、二三排、后门、后侧围、隐蔽机构及全舱空间比例。皮革、木纹、金属、颜色、反射与光照均为程序近似，不能以手册渲染图推定实车材质参数。

模型没有真实碰撞检测、防夹传感器、机构受力和人体工学验证。开合与姿态动画只表达仿真状态，不证明实车可达行程或安全条件。光照、玻璃和遮蔽效果依赖浏览器与图形设备；本说明不承诺帧率、显存占用或照片级画质。

本轮外观升级没有接入原生小艺或真实车辆。语音识别仍由浏览器提供，中文理解与执行条件仍来自本地规则。功能依据见[证据说明](evidence.md)，实际验收结果统一记录在[验证记录](validation.md)。

## 第五版：曲面、软包与材质精修

2026 年 10 月 2 日，本轮以第四版现有截图中可见的硬折面、后排软垫叠块和偏亮饰面为改进对象，继续沿用已查看的官方手册及汽车之家全景作为视觉参考。没有新增模型或照片贴图资产，也没有新增实车尺寸、后排机构或材质参数的证据。

| 改动范围 | 具体调整 | 边界 |
